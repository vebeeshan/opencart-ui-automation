\### API Test Suite



The API test suite was deliberately skipped for this submission because the implemented scope focused on the required OpenCart UI automation scenarios.



The available time was prioritized toward completing and stabilizing the end-to-end browser automation, test-data handling, cleanup, and Docker execution.



The framework can be extended with API tests in the future without changing the existing UI automation structure.
